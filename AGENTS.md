# Repository instructions

- Use English for repository documentation and code. Communicate with the project owner in Russian.
- Keep Android UI, site integration, reminder policy, and updates separate.
- Treat www.rngdle.com as the authority for rolls and account data. Use the original site UI for authenticated operations until an authorized API is documented.
- Keep email links, cookies, credentials, and signing material out of logs, tests, backups, and Git.
- Never generate a roll in background jobs or automate the site's interactive controls.
- Run the unit tests and Android build after changes. Record live-site and device checks separately from build results.
